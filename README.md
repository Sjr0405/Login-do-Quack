# Quack - Frontend

Este é o repositório do frontend do projeto Quack. O Quack é uma plataforma educativa voltada para programadores, desenvolvida como Trabalho de Conclusão de Curso (TCC) no curso técnico do SENAI.

## Sobre o Projeto

O Quack nasceu para resolver um problema crítico na área de TI: a dificuldade de encontrar conteúdo educativo de qualidade em português e a alta taxa de evasão em cursos de tecnologia. 

Dados que motivaram o projeto:
- Um relatório da Brasscom estima que as empresas de tecnologia demandem 797 mil talentos de 2021 a 2025.
- De acordo com o Mapa do Ensino Superior no Brasil 2023, a taxa de evasão nos cursos de graduação na área de TI supera a média de todas as áreas de ensino.

Muitas pessoas desistem por falta de um guia claro ou pela barreira do idioma. Nossa solução é uma plataforma que utiliza "Roadmaps" (guias de estudo) para orientar os usuários. O diferencial do Quack é focar em conteúdo prático em português e usar mecânicas de gamificação, como um sistema de coleção de emblemas e criação de comunidade, para incentivar os estudantes a continuarem praticando e não desistirem.

## Tecnologias

No frontend, estamos utilizando:
- React
- TypeScript
- Vite

O código principal da aplicação está dentro da pasta `react-teste=ing`.

## Como rodar o projeto

1. Faça o clone deste repositório.
2. Acesse a pasta `react-teste=ing`.
3. Instale as dependências com `npm install`.
4. Inicie o servidor de desenvolvimento com `npm run dev`.
